type ClaveCesar = Int #

cifrarCesar :: Alfabeto -> ClaveCesar -> String -> String #

Utilizamos la función transformarLetras de las utilidades para aplicar a cada uno de los caracteres de la cadena a cifrar la función que suma la clave de cifrado para hacer el "recorrido" que se hace al cifrar con César.

descifrarCesar :: Alfabeto -> ClaveCesar -> String -> String #

Hacemos el mismo procedimiento pero restando la clave (usando la función subtract) para aplicar el retroceso de k módulo longitud del alfabeto y así hacer el recorrido inverso sabiendo la clave k.
