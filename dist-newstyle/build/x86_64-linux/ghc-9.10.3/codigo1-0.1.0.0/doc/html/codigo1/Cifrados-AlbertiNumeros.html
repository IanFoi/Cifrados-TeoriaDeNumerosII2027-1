cifrarAlbertiNumeros :: Alfabeto -> ClaveAlbertiNumeros -> String -> String #

Cifra un texto de Alberti pero ahora con los números disparando el cambio de giro. Usamos normalizarExteriorNumeros para arreglar las letras. Al ir recorriendo la lista, usamos lookup en el resultado de alinearDiscosNumeros para ver en qué se cifra la letra. Luego usamos elem para checar si el símbolo original era "1234"; si sí lo era, la función cambia la llave interior \(@innerKey@\) usando ese carácter cifrado como el nuevo pivote de rotación para la recursión.

descifrarAlbertiNumeros :: Alfabeto -> ClaveAlbertiNumeros -> String -> String #

Descifra Alberti usando números como pivotes. Como los números se cifraron, tenemos que buscarlos al revés. Filtramos el disco con filter y sacamos el primer carácter que coincide usando fst y head. Después, usamos elem para preguntar si esa letra original que acabamos de sacar está en "1234". Si resulta que sí era uno de los números indicadores, lo usamos para hacer que la recursión gire el disco \(@innerKey@\) y no lo escribimos en el texto claro final.
