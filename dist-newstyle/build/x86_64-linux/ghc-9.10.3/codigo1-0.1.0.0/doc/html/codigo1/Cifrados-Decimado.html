descifrarDecimado :: Alfabeto -> ClaveDecimado -> String -> String #

Función para hacer el descifrado decimado. Para ello, necesitamos el inverso modular de la clave k, con lo que utilizamos la función de utilidad inversoModular para obtener el inverso y multiplicar lo obtenido con la representación numérica de cada carácter en la cadena. Utilizamos la expresión case porque solo se puede descifrar si es que existe el inverso modular, y esto ocurre siempre que la llave k y la longitud del alfabeto son primos relativos. Si es que existe, hacemos el procedimiento que se describió.
