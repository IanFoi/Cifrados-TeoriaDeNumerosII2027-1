type ClaveAfin = (Int, Int) #

cifrarAfin :: Alfabeto -> ClaveAfin -> String -> String #

Hacemos el cifrado Afín combinando dos cifrados. Primero aplicamos el cifrado decimado usando cifrarDecimado con el factor a y luego usamos cifrarCesar para sumarle el desplazamiento b. Esto representa la fórmula matemática \(E_{a,b}(x) \equiv a \cdot x + b \pmod{m}\).

descifrarAfin :: Alfabeto -> ClaveAfin -> String -> String #

Para el descifrado Afín, hacemos las operaciones al revés. Primero usamos descifrarCesar con la llave b para deshacer la suma. Después usamos inversoModular para revisar si el coeficiente a tiene inverso modular (si es primo relativo con la longitud del alfabeto). Si lo tiene, usamos transformarLetras para multiplicar el resultado por el inverso de a. Si no, regresamos un mensaje de error.
