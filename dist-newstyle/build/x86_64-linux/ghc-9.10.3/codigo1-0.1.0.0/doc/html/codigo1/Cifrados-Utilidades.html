indiceLetra :: Alfabeto -> Char -> Maybe Int #

Busca una letra del alfabeto y devuelve su posicion en el alfabeto, como puede ser un simbolo que no pertenezca al alfabeto devuelve Maybe Int, devolviedo Just posicion la posicion de la letra o Nothing. Lee la lista del alfabeto y usa elemIndex para obtener el indice.

letraDeNumero :: Alfabeto -> Int -> Char #

Dado un numero, devuelve una letra correspondiente a la posicion en el alfabeto, como podemos recibir un numero mayor a la cantidad de letras en el alfabeto, trabajamos con modulos para hacer que el alfabeto funcione de manera circular como con los circulos que usabamos en cifrado. Utiliza el operador !! para obtener el elemento que se encuentra en la posicion i en modulo m con m la longitud del alfabeto(obtenida por length).

transformarLetras :: Alfabeto -> (Int -> Int) -> String -> String #

Recibe el alfabeto, una formula y una cadena de texto. Aplica la formula a todos los caracteres que pertenecen al alfabeto para aplicar la funcion a toda la cadena sin necesidad de aplicarlo en el codigo principal logrando que el codigo principal sea mucho mas limpio, directo y facil de leer. Los caracteres que no pertenecen al alfabeto (como espacios) se dejan intactos.

inversoModular :: Integral a => a -> a -> Maybe a #

Funcion para encontrar el inverso modular a partir de resolver la congruencia ax =/ 1(mod m). Recibe el numero alpha, el modulo y devuelve el numero x correspondiente a alpha-1. Como el inverso modular solo existe si alpha y m son coprimos (a,m) = 1, devuelven Maybe Int pues no podemos asegurar que exista el inverso. Finalmente, la funcion utiliza la implementacion del algoritmo de Euclides.

algEuclides :: Integral a => a -> a -> (a, a, a) #

Implementacion recursiva del algoritmo de Euclides. Devuelve una tripla (g, x, y) tal que a*x + b*y = g = mcd(a, b)

multiplicarMV :: [[Int]] -> [Int] -> [Int] #

Funcion para multiplicar una matriz NxN por un vector de tamano N.

romperCadena :: Int -> [a] -> [[a]] #

Funcion para romper la cadena a cifrar en el cifrado Hill en pedazos proporcionales al tamano de la matriz, si el ultimo bloque queda incompleto se repite la ultima letra

removerIndice :: Int -> [a] -> [a] #

Funcion auxiliar que elimina un elemento de una lista dado su indice (empezando en 0). La usamos para eliminar la columna correspondiente al crear la submatriz.

determinante :: [[Int]] -> Int #

Funcion para encontrar el determinante de una matriz general NxN usando la Expansion de cofactores. Usamos esta informacion para saber que la matriz tiene inversa, pues necesitamos que el maximo comun divisor entre el determinante y la longitud del alfabeto sea 1 para que podamos descifrar.

adjunta :: [[Int]] -> [[Int]] #

Calcula la matriz adjunta (transpuesta de la matriz de cofactores). Necesaria para encontrar la inversa de una matriz general.

inversaMatrizMod :: [[Int]] -> Int -> Maybe [[Int]] #

Calcula la matriz inversa en aritmetica modular siguiendo la formula A^-1 = det(A)^-1 * Adj(A) (mod m)

expMod :: Integer -> Integer -> Integer -> Integer #

Funcion recursiva para hacer la exponenciacion modular rapida b^e mod m. Si bien Haskell ya tiene una funcion similar powMod para hacer esto, vale la pena el implementarla como ejercicio.

letraANumeroRSA :: Alfabeto -> Char -> String #

Funcion para convertir una letra en un codigo numerico RSA, funciona similar a la funcion que ya implementamos pero agrega una codificacion base para el espacio ' ' ademas de que ningun bloque debe de iniciar con cero, por lo que le sumamos 11 para que el primer elemento del alfabeto, generalmente a, tenga esta codificacion. Acepta cualquier alfabeto proporcionado por el usuario dando una codificacion a partir de su posicion en la lista. Usamos una cadena en vez de un entero para poder agrupar como se hace en RSA.

numeroALetraRSA :: Alfabeto -> String -> Char #

Funcion para convertir una cadena de dos digitos y devuelve su representacion como letra del alfabeto. Utilizamos String para poder desempaquetar las cadenas del procedimiento RSA.

tamanoBloque :: Integer -> Int #

Calcula dinamicamente el tamano maximo de un bloque de cifrado RSA para asegurar que el bloque en texto plano siempre sea menor que N. Ej: Si N=3233 (4 digitos), los bloques deben ser de 2 digitos.

partirEnBloques :: Int -> String -> [String] #

Parte una cadena en pedazos de tamano k.

calcularClavePrivada :: Integer -> Integer -> Integer -> Maybe (Integer, Integer) #

Genera la clave privada (n, d) a partir de los numeros primos p y q, y el exponente publico e. Utiliza el inverso modular para encontrar d tal que e * d = 1 (mod phi(n)).

enteroABaseL :: Alfabeto -> Int -> Integer -> String #

Convierte un numero entero a una cadena de letras de tamano fijo K usando la codificacion en Base-L. (Donde L es la longitud del alfabeto). Esto transforma la basura numerica de RSA a texto legible.

baseLAEntero :: Alfabeto -> String -> Integer #

Convierte una cadena de letras en Base-L matematicamente de regreso a un numero entero gigante.

longitudBaseL :: Alfabeto -> Integer -> Int #

Calcula dinamicamente el tamano maximo de letras que ocupamos en Base-L para poder representar un numero menor a N sin que se desborde.
