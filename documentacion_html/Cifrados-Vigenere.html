procesarVigenere :: Alfabeto -> ClaveVigenere -> String -> Bool -> String #

Función auxiliar para el Cifrado Vigenère. Para evitar que la clave se desacomode cuando hay espacios o símbolos, recorremos el texto a mano. Revisamos si cada carácter está en el alfabeto usando indiceLetra. Si está, tomamos el desplazamiento de la clave y sumamos o restamos dependiendo si queremos cifrar o descifrar. Usamos recursión para ir avanzando en la clave (ks) o repetir el ciclo (cicloClave) solo cuando las letras son válidas.

cifrarVigenere :: Alfabeto -> ClaveVigenere -> String -> String #

Llamamos a la función procesarVigenere pasándole un True para indicar que queremos sumar el desplazamiento de la clave.

descifrarVigenere :: Alfabeto -> ClaveVigenere -> String -> String #

Llamamos a la función procesarVigenere pasándole un False para indicar que queremos restar el desplazamiento de la clave.
