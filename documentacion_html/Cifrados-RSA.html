cifrarRSA :: Alfabeto -> ClavePublicaRSA -> String -> String #

Cifra un texto con RSA. Convertimos cada letra de la cadena en un número de dos dígitos usando letraANumeroRSA. Con la función tamanoBloque calculamos k, que es cuántos dígitos podemos juntar sin pasarnos de n. Si el texto no cabe exacto en bloques de tamaño k, le rellenamos con nueves ("99") al final. Cortamos el texto con partirEnBloques y elevamos cada bloque usando expMod para calcular \(M^e \pmod{n}\). Al final regresamos los números separados por espacios con unwords.

descifrarRSA :: Alfabeto -> ClavePrivadaRSA -> String -> String #

Descifra RSA. Recibe los números separados por espacios, los extrae con words y los pasa a enteros con reads. Los elevamos al exponente privado d usando expMod para sacar \(C^d \pmod{n}\). Después de eso, recuperamos los ceros que se hayan perdido a la izquierda con un replicate para que todos los bloques midan exactamente k. Por último, volvemos a separar en parejitas de 2 dígitos y las convertimos a letras con numeroALetraRSA.
