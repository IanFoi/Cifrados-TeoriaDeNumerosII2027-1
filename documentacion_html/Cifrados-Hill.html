type ClaveHill = [[Int]] #

cifrarHill :: Alfabeto -> ClaveHill -> String -> String #

Hace el cifrado de Hill multiplicando matrices. Primero revisamos si se puede invertir la matriz usando determinante y algEuclides, verificando que el determinante y el tamaño del alfabeto sean primos relativos. Limpiamos el texto con filter para quitar caracteres inválidos (los que no pasan indiceLetra). Después partimos el texto en bloques del tamaño de la matriz con romperCadena, multiplicamos la llave por cada bloque usando multiplicarMV y regresamos los números a letras con letraDeNumero.

descifrarHill :: Alfabeto -> ClaveHill -> String -> String #

Descifra un texto de Hill calculando la matriz inversa modular. Usamos la función inversaMatrizMod que internamente saca la adjunta y multiplica por el inverso del determinante módulo la longitud del alfabeto. Con un case checamos si existe la inversa; si sí, volvemos a llamar a la función cifrarHill pasándole la matrizInversa en lugar de la original, ya que descifrar es como volver a cifrar pero con la matriz inversa.
