cifrarAlbertiLetras :: Alfabeto -> ClaveAlbertiLetras -> String -> String #

Hace el cifrado usando los Discos de Alberti con puras letras. Empleamos normalizarExterior y toUpper para limpiar el texto de entrada y cambiar letras equivalentes (como la J por la I). Recorremos el texto usando recursión para llevar la cuenta de la posición del disco. Con un isUpper verificamos si la letra es mayúscula; si lo es, usamos alinearDiscos (que usa elemIndex para ver cuánto rotar el disco interior) y actualizamos la posición, imprimiendo la mayúscula sin cifrar. Si es minúscula, la buscamos y la ciframos normalmente.

descifrarAlbertiLetras :: Alfabeto -> ClaveAlbertiLetras -> String -> String #

Descifra un texto de Alberti en letras. Al igual que el cifrado, usamos un condicional isUpper al recorrer la lista recursivamente. Si leemos una mayúscula, actualizamos el índice externo \(@idxOut@\) y pasamos al siguiente carácter de la cadena (\(@cs@\)) ignorando la mayúscula en el resultado. Si es una minúscula, llamamos a alinearDiscos y usamos filter para buscar qué letra del exterior le toca. Si por algo no la encuentra, ponemos un ? para que no falle.
